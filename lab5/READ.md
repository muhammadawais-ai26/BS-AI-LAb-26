# Lab 5 - Adversarial Search
## Minimax and Alpha-Beta Pruning

### Objective
The objective of this lab is to implement Minimax and Alpha-Beta Pruning algorithms and understand how they work in game trees.

### Introduction
Minimax is an algorithm used in two-player games. It helps a player choose the best possible move.

MAX tries to get the highest value, while MIN tries to get the lowest value.

Alpha-Beta Pruning improves Minimax by avoiding unnecessary branches.
